# Held

Entry for [Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) ($50, make.fun).

`main.py` (Python 3.13 stdlib, no network) writes one short text to
`/output/entry.txt` — a quiet kitchen at two in the morning, written to
relax the AI judge reading it: calm shown through a concrete scene, not
told through instructions.

Run it:

```sh
python3 main.py
```
